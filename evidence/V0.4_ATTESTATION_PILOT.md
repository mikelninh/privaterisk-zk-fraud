# PrivateRisk V0.4 — signed-attestation pilot evidence

## Claim
PrivateRisk V0.4 can ingest an explicit payment-event envelope, verify three cryptographically signed trust attestations, generate the funding-sufficiency Compact/PLONK proof in a real Chromium browser, feed only verified predicates into deterministic fraud policy, and persist a pilot audit record across browser refreshes.

No real customer PII, account records or bank data are used.

## Key-custody truth boundary

The ES256 signatures are real. The V0.4 demo issuers create ephemeral, non-exportable P-256 signing keys in the browser at runtime. This avoids committing reusable private keys while exercising the issuer-registry and signature-verification boundary.

This does **not** represent production issuer custody. Real attestor signing keys must live outside the client in a controlled service/HSM/KMS/MPC-style boundary with onboarding, rotation and revocation controls.

## Midnight network truth boundary

The Compact/PLONK proof is real and generated locally in the browser. The network adapter intentionally reports:

```text
PREPROD_NOT_CONFIGURED
NOT SUBMITTED
```

V0.4 does not claim a Preprod contract address, chain transaction, confirmation or finality. See `docs/MIDNIGHT_PREPROD_RUNBOOK.md` for the concrete next gate.

## Production-readiness boundary

This evidence proves a pilot integration slice. It does not prove bank-production readiness, regulatory approval, production key custody, real external issuer trust, Kafka/payment-rail connectivity, append-only server-side audit infrastructure, HA/SLOs, penetration testing, or live fraud-model performance.
